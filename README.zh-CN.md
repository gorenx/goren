# Goren

Goren 探索一个面向 Agent Memory 静态记忆产品的可复用 Memory Agent。此类产品通常重点解决长期事实、偏好、指令或摘要如何存储、组织和召回，但往往缺少一个独立的语义组件，用来持续理解对话中的知识变化。

本项目关注如何从对话上下文中抽取可配置的知识对象，通过只读接口获取相关已有信息，并让 LLM 直接输出用户对每项知识的最终立场：支持、反对或不确定。知识对象类型由接口、Schema、Prompt 和响应解析器定义；Agent 核心不固定具体类型，也不关心 Knowledge 如何存储或管理。
